# 🎨 نظام وتوجيهات التصميم القياسي لواجهات النظام (Enterprise UI Design System)

تم اعتماد هذا الميثاق لضمان توحيد وتناسق الروح البريميوم، الأناقة البصرية، والراحة الكاملة للعين عبر كافة موديولات وصفحات النظام (ERP / SaaS Standard).

---

## 1. الفلسفة البصرية العامة (Visual Philosophy)
* **واجهة هادئة خالية من الضوضاء البصرية (Minimal & Calm UI)**: تجنب الألوان الصارخة والفاقعة، الخلفيات المشبعة، والأشرطة العلوية الملونة فوق الكروت.
* **التباين الذكي والراحة للعين (High Legibility & Ergonomics)**: الاعتماد على درجات الرمادي والـ Slate الناعمة (`#f8fafc`، `#e2e8f0`، `#cbd5e1`) مع نصوص واضحة وداكنة (`#0f172a`، `#1e293b`، `#475569`).
* **التوافق التام مع اللغة العربية (RTL First)**: جميع النصوص، الجداول، الكروت، والهيدرز مصممة من اليمين إلى اليسار تلقائياً مع دعم محاذاة الأرقام الإنجليزية/السيريالات (`dir="ltr"`).

---

## 2. كروت المؤشرات العلوية (KPI Dashboard Metric Cards)
* **الخلفية والإطار**: خلفية بيضاء نقية (`#ffffff`)، إطار ناعم (`border: 1px solid #e2e8f0`)، زوايا مستديرة (`borderRadius: 10px`)، وظل خفيف جداً (`box-shadow: 0 1px 2px rgba(0,0,0,0.03)`).
* **حاوية الأيقونة**: صندوق رمادي هادئ وموحد (`width: 38px`, `height: 38px`, `background: #f8fafc`, `border: 1px solid #e2e8f0`, `color: #64748b`).
* **النصوص والأرقام**:
  * عنوان المؤشر: خط شبه عريض (`fontSize: 0.78rem`, `fontWeight: 600`, `color: #64748b`).
  * القيمة الرقمية: خط عريض بارز (`fontSize: 1.35rem - 1.4rem`, `fontWeight: 800`, `color: #0f172a`).

---

## 3. معيار كبسولات الحالات (Soft Pastel Semantic Badges)
الحالات هي العنصر الوحيد الذي يأخذ ألواناً دلالية مميزة لمساعدة العين على المسح السريع (Visual Scanning) ولكن بدرجات **باستيل ناعمة وغير فاقعة**:

| الحالة (Status) | درجات الألوان القياسية (Pastel Palette) | الاستخدام النموذجي |
| :--- | :--- | :--- |
| **جاهز للتسليم / مكتمل / متاح** | `bg: #ecfdf5`, `border: #a7f3d0`, `color: #065f46` | الأجهزة المصلحة، الفواتير المسددة، الأصناف المتوفرة |
| **قيد الصيانة / قيد التنفيذ** | `bg: #fffbeb`, `border: #fde68a`, `color: #92400e` | العمل الجاري، الفحص، أذونات الصرف المفتوحة |
| **استلام جديد / كسر زيرو / مباع** | `bg: #f0f9ff`, `border: #bae6fd`, `color: #0369a1` | تذاكر جديدة، أجهزة كسر زيرو، فواتير بيع |
| **تم التسليم / مستعمل / عادي** | `bg: #f8fafc`, `border: #e2e8f0`, `color: #475569` | المنتهي خالص، الأجهزة المستعملة العادية |
| **تعذر الإصلاح / ملغي / تالف** | `bg: #fff1f2`, `border: #fecdd3`, `color: #9f1239` | الأجهزة المرفوضة، المرتجعات، قطع الغيار التالفة |

---

## 4. أزرار وأشرطة الفلترة (Segmented Control Tabs)
* استخدام حاوية رمادية فاتحة متصلة (`background: #f8fafc`, `padding: 3px`, `border: 1px solid #e2e8f0`, `borderRadius: 8px`).
* التبويب النشط (Active): خلفية بيضاء (`#ffffff`)، إطار ناعم (`#cbd5e1`)، وظل خفيف (`0 1px 2px rgba(0,0,0,0.04)`).
* **عدادات مدمجة (Mini Count Badges)**: إظهار عدد العناصر بجانب اسم التبويب ببادج كبسولي صغير (`padding: 1px 6px`, `borderRadius: 10px`, `fontSize: 0.68rem`).

---

## 5. مكتبة الأيقونات (Vector SVG Icons Standard)
* **المعيار**: الاعتماد الكامل على أيقونات SVG Vector نقية بـ `strokeWidth="1.75"` ومقاسات مدمجة (`14px` إلى `16px`).
* **القاعدة الصارمة**: يُمنع استخدام الإيموجي أو الأيقونات الكرتونية الملونة في الجداول أو الكروت الرئيسية.

---

## 6. الجداول والإجراءات السريعة (Tables & Actions)
* **رأس الجدول (TableHeader)**: خلفية `#f8fafc` مع خط غامق بارز `#475569` بحد سفلي `#e2e8f0`.
* **أزرار الإجراءات في السطر**: أزرار بيضاء أنيقة متناسقة (`background: #ffffff`, `border: 1px solid #e2e8f0`, `color: #334155`, `borderRadius: 5px`) مع أيقونة مصغرة مدمجة.
* **النسخ بنقرة واحدة (Click-to-Copy)**: تفعيل زر النسخ السريع بجانب أرقام الهواتف والسيريالات لتقديم أفضل تجربة مستخدم سريعة.
